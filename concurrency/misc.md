std::future / std::shared_future
- Helps with lazily getting the value of an async call.
- future -> can only get result once, shared -> can get many times

std::packaged_task same as std::function but value can be returned async

std::memory_order_fence
- Underlying idea/implementation of atomic store/load orderings: prevent operations before/after the fence from being reordered
